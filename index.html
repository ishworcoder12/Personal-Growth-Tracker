Sends today's values, ladder, exposure reps and check-in note to Claude — free, via a Puter.js account instead of a paid API key — for a short ACT-informed reflection. Not therapy, not a diagnosis, just a second perspective.

No API key needed — the first time you analyze or test, a free Puter.com sign-in popup appears once; after that it's free and unlimited under Puter's "you sign in, they cover the model cost" plan. If you're running this through a "website to APK" wrapper and the popup or request silently fails while the same page works fine in Chrome, the wrapper's WebView is likely blocking it — not this app. Rebuilding the APK as a Trusted Web Activity / Bubblewrap build (which is just Chrome) is the most reliable fix.
